# Classless Pure CSS

Pure.css style, class-less css ui framework for resource constrained MCU. The code was extracted from Pure.css using AI.

## Goals

considering the reources constrained in embedded system(resource constrained MCU), 
this framwork not aimed at full functionity, beautiful, interactive;
but concentrate on 
- minimal footprint
- compact layout
- zero dependency
- modern style eg switch & theme
- easy study
